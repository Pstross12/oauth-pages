Privacy policy

Last updated: 11 November 2026

Studio OS is an internal tool run by a small music production studio on its own server for its own team members. It is not offered to the public.

What Google data the tool uses

When a team member connects their Google account, Studio OS requests access to Google Calendar and Google Sheets. It uses this access only to:

  • read the member's calendar events and show them inside Studio OS,
  • create, update and delete deadline and availability events in a calendar the studio has chosen for this purpose,
  • create spreadsheets with project data on request and read spreadsheets the member explicitly chooses to import.

Storage and sharing

Access tokens are stored encrypted on the studio's own server, which is reachable only over the studio's private network. Calendar event data is kept only as long as needed to display it. No Google user data is sold, shared with third parties, used for advertising, or used to train AI models.

Revoking access

A team member can disconnect their Google account in Studio OS at any time, which deletes the stored tokens, or revoke access at myaccount.google.com/permissions.

Contact

Questions about this policy go to the studio's administrator, whose email is listed on the Google consent screen as the support contact.

Studio OS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
